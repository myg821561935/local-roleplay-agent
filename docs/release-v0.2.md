# v0.2 资源库与剧本工坊发布说明

## 版本定位

v0.2 把外部社区素材从“直接导入当前配置”调整为“先入库、再组合、最后应用”。它仍是仅供本机单用户使用的预览稳定版，默认监听 `127.0.0.1:5178`，并完整继承 v0.1 的启动、备份恢复、Provider 测试连接和数据迁移能力。

数据模式版本升级为 `v2`。首次启动会自动创建：

```text
data/library/resources/
data/library/packs/
```

原有角色卡、世界书、Prompt、会话与备份格式保持兼容。

## 资源导入流程

1. 在检查器中打开“资源库”。
2. 通过“本地素材”选择文件，或在“在线采集”中搜索已配置来源。
3. 先查看导入体检：识别格式、完整度、警告、重复项与同名冲突。
4. 确认后写入本地资源库；当前会话不会被自动覆盖。
5. 在“剧本工坊”选择基底剧本、角色、世界书与 Prompt，生成自定义剧本。
6. 点击“应用”后，才会通过统一的会话配置流程更新当前会话。

## 适配器与来源记录

内置适配器包括：

- Character Card V2 JSON/PNG 元数据。
- SillyTavern Lorebook JSON。
- 文本或 YAML 参考素材。
- 社区通用 JSON，用于暂未建立专用格式的类脑社区等来源。

每份素材保存来源名称、来源链接、作者、许可证、标签、适配器、导入时间和内容指纹。完全重复的素材不会重复写入；同名但内容不同的素材会提示冲突，由创作者决定是否保留。

社区通用适配器只做结构化归档，不声称兼容社区未公开或尚未取得样本的专有格式。拿到真实样本后，应新增专用适配器和回归测试，不在通用解析器里堆叠猜测。

## 剧本组合规则

- 基底剧本提供规则系统、视觉主题、背景图片和默认内容。
- 可以保留或排除基底世界书，再追加任意已入库世界书。
- 可选一张角色卡覆盖基底主角，并追加一个 Prompt 资源。
- 生成的自定义剧本拥有独立 ID，并写入 `data/library/packs/`。
- 应用后会话记录自定义剧本 ID；主题与背景通过 `visualPackId` 继承，不会把内容身份错误切回基底剧本。
- 删除资源不会破坏已生成剧本，因为剧本保存的是组合后的快照；删除剧本不会删除原始素材。

## 内容与执行边界

资源库不对虚构题材、成人创作或叙事内容增加额外过滤。安全体检只关注可能触发本机执行的配置，例如脚本、shell 命令、子进程或 MCP 启动配置。所有导入内容默认仅按数据保存，不会自动执行其中的命令或代码。

## 发布验收

```bash
npm run release:check
```

验收至少覆盖：

1. v0.1 的会话、备份、恢复、Provider 与流式对话回归测试。
2. 数据自动迁移至 `v2`，重复迁移保持幂等。
3. 本地导入预览能返回体检结果和适配器信息。
4. 重复素材不会产生重复记录，同名冲突会被标记。
5. 自定义剧本可以创建、枚举、应用和删除。
6. 自定义剧本应用后保持自己的内容 ID，并正确继承基底视觉包。
7. 桌面和窄屏下资源库可滚动、可展开，三个工作视图均可访问。

## 发布边界

- 不直接开放公网访问，没有多用户账号和远程鉴权。
- 外部来源是否允许下载、转载和二次使用，应以原作者与站点许可证为准。
- API Key 和包含它的备份仍需按敏感文件保管。
- 大批量社区资源的标签清洗、去重合并和专用格式转换将在取得真实样本后继续演进。
