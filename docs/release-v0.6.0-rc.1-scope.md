5. **叙事 Agent**：角色卡/世界书优先 Prompt 装配、输出协议、思考过程隔离、推荐行动与 MCP function calling。
6. **长期连续性**：Scene/Chapter/Arc 分层记忆、向量召回、事实卡、SQLite 剧情知识图谱、关系图和分支失效。
7. **世界模拟**：声明式动作、事件账本、NPC 目标/知识/日程、势力关系、世界时钟与状态裁定。
8. **本地治理**：Provider 凭据遮罩、会话配置迁移、健康检查、备份恢复、仓库边界和本机样例审计。

## 明确排除

以下内容只允许保留在本机，不属于 Git 里程碑范围：

- 社区角色卡、世界书、Prompt 预设、正则包、重前端网页或 APK 原件；
- 角色立绘、背景图和作者未授权再分发的素材；
- 用户故事、会话、记忆、图数据库、备份和导入缓存；
- Provider API Key、Cookie、授权令牌、Discord 或其他平台登录状态；
- 本机黄金样例原件。仓库只保存脱敏 fixture、结构化 manifest 约定和测试代码。
