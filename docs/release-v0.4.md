# v0.4 世界模拟发布说明

## 本次目标

v0.4 把 v0.3 的动作协议、事件账本和世界状态裁定扩展为最小的多 NPC 世界模拟闭环。角色不再只是 Prompt 文本，而是拥有位置、目标、公开知识、私有知识、关系、日程和幕后议程的独立行动者。

## 世界状态闭环

1. Prompt 组装器把当前世界时钟、NPC 状态与信息边界注入模型上下文。
2. 模型输出叙事正文，并可附带隐藏的 `lra.action/v1` 动作块。
3. 服务端校验协议、修订号、条件、动作类型和目标路径。
4. 裁定器生成精确效果并更新世界状态与 NPC 状态。
5. 事件账本保存剧情回合、手工动作、角色档案修改和世界时钟推进。
6. 重生成、Swipe 切换与历史编辑按当前分支回放动作，防止状态串线。

协议说明见 `docs/action-protocol-v1.md`。

## 多 NPC 与幕后世界

- 内置玄幻、灵异、明末、仙侠剧本各补入主角与至少三名自主 NPC。
- NPC 档案区分公开知识与私有知识，并可声明目标、位置、状态、关系、日程和幕后议程。
- 推进世界时钟时，会执行跨过时刻的 NPC 日程，更新角色位置和状态，并生成幕后事件。
- 状态检查器新增“幕后 / 公开”投影、世界时钟、角色运行和事件账本。
- NPC 原始档案只在高级折叠区编辑，正常创作流程默认显示结构化信息。

## 数据迁移

- 应用版本：`0.4.0`
- 数据 schema：`3`
- 启动时为旧会话补充 `simulation`、世界状态基线、模拟基线和动作回放检查点。
- 旧消息、世界状态、记忆卡和事件账本原样保留。
- 执行迁移前建议先运行 `npm run backup -- --reason pre-v0.4`。

## 当前边界

- NPC 日程由剧情动作或创作者推进世界时钟触发，不运行常驻实时后台进程。
- 模型只能提交声明式动作，不能执行第三方脚本或任意工具调用。
- 私有知识约束依赖服务端投影和 Prompt 信息边界；公开视图不会返回私有字段。
- v0.4 是稳定自用候选版，上线前仍应使用自己的 Provider 做连续长对话验证。
