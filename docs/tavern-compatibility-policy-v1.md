# 酒馆资源兼容政策 v1

## 定位

本项目兼容酒馆资源格式和常见交互语义，但不复刻酒馆的第三方代码运行环境。

以下边界不可放宽：

1. 格式兼容不等于运行时兼容。
2. 安全降级必须显式提示，不能静默丢失语义。
3. 没有真实样例与自动化测试数据，不宣称覆盖率。
4. 未知第三方 JavaScript、DOM 操作、iframe、网络请求与不可控递归不执行。

## 三态验收

### 完整映射

固定样例中的主要声明式行为与原资源语义一致，自动化快照或行为断言通过。完整映射只对已登记样例和已测能力负责，不代表同类市场资源全部兼容。

### 安全降级

静态角色、世界书、Prompt、图片和说明内容可以保留；不安全或未知能力保持禁用。导入报告必须列出差异、影响与处理建议，用户确认后才进入运行流程。

### 阻断运行

资源依赖动态脚本、DOM、iframe、网络调用、隐式全局对象或不可控递归时，可以保存原件供审阅，但不得作为可运行剧本启用。报告必须给出具体阻断项。

## 基准库

脱敏基准位于 `tests/fixtures/compatibility/`，目前覆盖：

- 纯文本角色卡。
- 安全显示正则卡。
- Quick Reply 与白名单状态命令卡。
- MVU 状态卡。
- 可静态转换的重前端信息面板卡。
- 必须阻断的动态脚本卡。

样例只保留实测字段结构和最小虚构文本，不包含社区原卡正文、图片、作者信息或可执行代码正文。新增兼容声明前，必须先补样例和验收断言。

## 受控语义

- 世界书二级关键词支持四种 `selectiveLogic` 语义。
- 显示正则替换支持 `{{char}}`、`{{user}}`。
- `/setvar`、`/incvar` 转换为 MVU 补丁，不直接解释执行脚本。
- `onImport`、`onUser`、`onAssistant` 只执行受预算约束的声明式补丁。
- 状态更新使用白名单路径和 `set`、`increment`、`delete`，任一步失败整次回滚。

预算常量由 `server/compat/lifecyclePolicy.js` 统一定义，执行器不得绕过。

## 变更要求

每次兼容能力扩展必须同时包含：

1. 脱敏结构样例。
2. 预期三态结论。
3. 行为或快照测试。
4. 导入报告中的用户可见差异。
5. 对未知脚本仍不执行的回归断言。

技术框架仓库不得提交第三方角色卡、世界书、Prompt、立绘或个人故事存档。
