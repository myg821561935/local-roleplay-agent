# v0.2.1 导入评定与主流程发布说明

## 本次目标

v0.2.1 将外部资源接入收敛为一条可审阅的创作流程：获取素材、生成技术评定、确认入库、进入剧本组装。它不改变数据 schema，现有 v0.2 资源与自定义剧本可直接继续使用。

## 导入评定

每次导入都会生成五个维度的技术报告：

- 结构完整：角色核心字段、世界书条目或 Prompt 内容是否齐备。
- 运行可用：角色约束和示例对话、世界书触发条件、Prompt 指令信息是否足够。
- 一致性：同名内容、重复触发词、无效正则和可执行配置标记。
- 上下文效率：资源总体积、世界书常驻内容和预计 token 占用。
- 来源信息：适配器、站点、文件、作者和版本是否可追溯。

评定只检查格式、兼容性和运行质量，不评价题材或创作内容。脚本、Shell、MCP 等配置片段只作为文本保存，不会自动执行。

## 导入行为

默认操作是“存入素材库”，不会覆盖当前创作配置。勾选“同时载入当前创作配置”后，才会沿用旧版行为，将角色卡或世界书写入当前配置。旧 API 客户端未传该选项时仍保持兼容。

完全重复的资源显示“已在素材库”并禁止重复确认；缺少关键内容的资源显示“暂不可入库”。同名但内容不同的资源保留为独立版本，交由创作者审阅。
