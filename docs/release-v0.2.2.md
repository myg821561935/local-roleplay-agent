# v0.2.2 插件适配与内容包版本发布说明

## 本次目标

v0.2.2 为资源扩展建立稳定边界：内容包负责携带可运行的剧本资产，插件负责声明外部格式如何被识别。两者都必须先经过版本、依赖与结构检查，再进入本地资源层。

## 内容包

- 使用 `lra.content-pack/v1` 自包含 JSON 格式。
- 清单包含内容包 ID、语义版本、引擎范围、能力和依赖。
- 内容区可携带角色卡、角色预设、世界书、Prompt、初始记忆、规则系统和视觉关联。
- 自定义剧本可从“剧本工坊”导出，再在另一份本地实例中预览并安装。
- 运行时必需依赖缺失或版本不匹配时禁止安装和应用；构建期或可选依赖只给出警告。

## 声明式插件

- 使用 `lra.plugin/v1` JSON 清单。
- 插件可以声明适配器 ID、格式、资源类型、匹配条件、优先级和能力。
- v0.2.2 不加载第三方模块，不执行脚本、Shell、命令或 Hook。
- 内置插件不可停用或删除；本地插件可在“资源库 > 扩展适配”中启停和移除。
- 停用插件不会删除已入库资源，只会从后续格式匹配中移除其适配器。

## 兼容策略

- 应用版本使用 SemVer 比较，支持精确版本、比较符、`^`、`~`、通配符、区间和 `||`。
- 旧自定义剧本没有显式 manifest 时，读取阶段会合成 `1.0.0` 清单。
- 数据 schema 不变，现有会话、素材库和剧本无需迁移。
