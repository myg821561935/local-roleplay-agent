# 剧本内容参考与原创边界

更新日期：2026-07-10

## 使用原则

- 参考对象只用于提炼世界构建、信息组织、冲突设计、章节节奏和人物对白方法。
- 不复制原作人物、组织、地名、功法、事件链、标志性对白或具体情节。
- 每个本地剧本维持自己的规则边界。玄幻不自动引入灵异禁忌，明末不出现修真资源，仙侠不套用现代刑侦权限。
- 用户提供的《英雄志》资料包可以作为该独立剧本的直接设定来源；其他作品仍只做方法参考。

## 近期行业信号

本轮参考了起点中文网公开榜单和作品官方简介。近期较强的共同趋势包括：

1. 世界规则直接制造人物选择，而不是只做背景说明。
2. 资源、身份、交通和组织执行链开始承担更多剧情功能。
3. 长篇作品更强调群像、信息差和可持续事件线，而不是单次副本结束即清零。
4. 修炼、灵异或历史机制必须有成本和可验证边界，读者才能相信主角的破局。

## 对话行文规范

参考用户提供的长篇对话截图，采用以下结构：

1. 先用一至两个具体感官细节锁定时间、空间和人物位置。
2. 让 NPC 通过动作、称谓、停顿和回避体现立场，不用旁白直接宣布所有心理。
3. 每轮至少推进一个事实、关系或事件时钟。
4. 世界设定通过行动后果自然显露，避免连续大段百科说明。
5. 普通场景保持中长篇幅，关键战斗、调查突破、朝议或关系决裂才扩大篇幅。
6. 在自然停顿处给出 3-5 个代价方向不同的选择，并始终允许用户自定义行动。

## Token 控制

- 世界圣经章节默认不是全部常驻，只在关键词、正则或相关语义命中时注入。
- 每个会话继续受 `maxInjectedCards` 限制；庞大世界书不会自动等于每轮庞大 Prompt。
- 稳定变化进入事实卡与世界状态，旧对话进入滚动摘要，避免反复携带完整历史。
- 创作方法条目只用于保持题材方向，不应盖过当前场景、角色卡和最近对话。
