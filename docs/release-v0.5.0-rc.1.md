# v0.5.0-rc.1 轻前端兼容冻结说明

## 定位

`v0.5.0-rc.1` 是面向社区轻卡实测的候选版。在 v0.4 世界模拟基础上，它补齐安全显示正则、文本 Quick Reply、声明式侧栏、安全 EJS 子集和 MVU 状态闭环。冻结后优先处理真实卡片的解析差异、状态错误和交互回归，不继续扩张任意脚本能力。

## 已完成闭环

- 导入预览识别酒馆助手、小白 X、正则脚本、Quick Reply、MVU、EJS、侧栏面板和 Prompt 顺序依赖。
- SillyTavern Prompt 预设可进入素材库和剧本拼装，实际保留 `prompt_order`、消息角色、相对位置及历史内 Depth/Order。
- 兼容报告分别表达“可安全保存”“可降级游玩”“可直接游玩”，缺少运行时不再被描述为完整兼容。
- MVU 初始值随角色卡或内容包进入故事会话，并注入安全、只读的模板上下文。
- 模型通过隐藏的 `lra.mvu-patch/v1` 控制块提交 `set`、`increment`、`delete` 操作；服务端验证 revision、路径、体积与序列化安全后才写入。
- MVU 控制块和流式过程中的不完整前缀不会显示在故事正文。
- Edit、重生成和 Swipe 切换按消息元数据重放当前分支 MVU，旧分支不会继续污染侧栏状态。
- 声明式面板和安全 EJS 会读取最新会话 MVU，显示规则只改渲染副本，不改原始消息。

## 明确不在本版范围

- 任意 JavaScript、DOM Hook、动态网络请求、自定义 iframe 与第三方事件生命周期。
- 完整 STscript、斜杠命令链、EJS 赋值与循环、酒馆助手或小白 X 的隐式全局对象。
- 需要可执行前端代码的重前端卡。此类资源可以保存原件并创建待完善副本，但不能标记为直接可玩。

## 真实轻卡测试清单

1. 导入前记录文件来源、卡片版本和导入兼容结论，确认按钮显示“直接游玩”或“仅安全保存”符合依赖报告。
2. 检查卡面、开场白、附带世界书、显示正则、快捷回复、侧栏面板和 MVU 初始值是否完整进入独立故事。
3. 连续对话 8 至 10 轮，观察状态面板是否随稳定事件更新，正文中不得出现 `lra-mvu-patch`、EJS 或内部分析标签。
4. 对同一回复执行重生成并在两个 Swipe 间切换，确认每个分支恢复自己的 MVU 值。
5. 编辑较早的用户消息，确认后续消息被截断后，世界动作和 MVU 都按保留分支重放。
6. 对标原卡说明，记录仍依赖外部脚本的按钮、变量更新、面板事件和 Prompt 锚点，作为后续适配器样本。

## 验证命令

```bash
npm run backup -- --reason pre-v0.5.0-rc.1-test
npm run release:check
npm start
```

停止或重启：

```bash
npm stop
npm restart
```

真实卡片、作者素材、导入图片与个人存档仍只保存在本机，不进入 GitHub 技术框架仓库。
