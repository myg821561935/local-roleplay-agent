# 英雄志群像剧本资料包

本目录由用户提供的 `hero_rpg_pack_v0.3` 整理而来，供本地角色扮演 Agent 读取。它是剧情推演资料，不是官方原文，也不把原作章节文本直接塞入 Prompt。

## 项目内文件

- `characters.json`：96 个角色、组织与多 Agent 阶段资料。
- `worldbook.json`：原资料包的 95 条角色世界书条目。
- `nodes.json`：45 个可调度剧情节点，包含登场角色、潜伏角色、开启条件和冲突信息。
- `gm-runner.md`：多 Agent 与 GM 调度说明。
- `sources.md`：资料来源、推断边界与可信度说明。

## 运行时补全

适配器位于 `server/config/yingxiongzhiPack.js`，加载时会组合：

- 7 条总纲、信息隔离、旧账和节点调度规则；
- 95 条原世界书角色资料；
- 1 条自动补齐的伍崇华角色资料；
- 45 条剧情节点世界书；
- 共 148 条可检索世界书；
- 12 张精选可直接扮演的角色卡，其余角色仍保留在世界书与多 Agent 调度资料中。

世界书条目带有 `player` / `gm` 可见性、剧透等级、信息来源、可信度、活跃 Agent 和潜伏 Agent 元数据。玩家开局稿只显示公开信息，GM 隐藏真相只参与后台调度。

## 推荐开局

- `E02`：乱世文章，卢云、顾倩兮与顾家线。
- `M01`：怒苍开山，秦仲海线。
- `M03`：正统军诞生，艳婷与伍定远线。
- `A01`：正统朝多视角时代。
- `B01`：八王世子红螺寺大典。
- `W23_01`：万方有罪开局。

直接修改源 JSON 后重启本地服务即可重新构建内容包；结构和数量由 `tests/contentPacks.test.js` 约束。
