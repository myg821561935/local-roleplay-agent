# 多 Agent 跑团运行器 v0.3

## 使用顺序
1. 读取 `角色卡_全书多agent_扩展_v0.2.json` 或本包附带的角色阶段时间线。
2. 读取 `逐章角色登场表_剧情节点_v0.3.json`，选择一个 `node_id` 作为开局。
3. GM 每轮只投放环境变量，不替角色决定行动。
4. 每个 Agent 按“时间线 + 已知信息 + 当前欲望 + 禁区”反应。

## 每轮 GM 投放格式
```yaml
node_id: W23_05
时间: 红螺寺围城第X日
公开环境:
  - 旧渠水量不足
  - 八王世子开始领营
  - 顾倩兮药帐登记病者
隐秘变量:
  - 卢云身份即将半公开
  - 杨绍奇散布井谣
  - 石刚进入怒苍营
强制约束:
  - 卢云不能被普通百官立刻认出
  - 苏颖超不知道正十七
  - 秦仲海称卢云为兄弟语境
```

## Agent 回合格式
```yaml
角色: 伍崇卿
当前已知: 他知道卢云与伍定远旧义，知道父亲被推向白起命运
误解/盲区: 不知道杨家井全貌
即时欲望: 救父亲，不让伍定远成为刀
行动: 用藏粮官漏洞逼问伍定远/卢云
台词风格: 冷、刺、少年反社会，但内核是救父
```

## 交锋规则
任何人与卢云交锋，都必须带三重旧账：
- 个人过往
- 与卢云的旧交集
- 当前利益/生死压力

例：伍定远不是“军法 vs 仁义”，而是“我已经害过你一次，还能再赌你的书生之见吗”。

## 信息隔离规则
- 玩家/GM 可以有上帝视角，角色不可以。
- 阿秀只用孩子称谓理解世界：娘、爹爹、铁脚大叔、三眼大叔、小红脸。
- 苏颖超只能把卢云水中身法误认为“仁剑之理”，不得知道正十七。
- 杨肃观不宜长篇自白，多通过别人视角显影。
- 秦仲海不能轻佻称卢云“死书生”，应是“卢兄弟/兄弟/卢云”。
